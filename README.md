============================== 程序介绍 ==============================

本程序主要应对笔记本、平板、无线键盘，没有锁定键指示灯的用户，按下功能键需要屏幕提示的用户。

本程序是基于 AutoHotkey v2.0 开发与运行的脚本程序；面向 Windows 7 及以上64位系统，键盘状态提示辅助工具。

在屏幕上直观实时显示 Caps Lock、Num Lock、Scroll Lock 三个锁定键的状态，以及 Shift、Ctrl、Alt、Win 四个功能键的按键提示；

程序界面精简、运行轻量、响应灵敏、不占地方。

功能：

键盘指示灯：显示 Caps Lock、Num Lock、Scroll Lock 锁定键的状态指示灯。切换相应键时显示“锁定（灯亮）/解锁（灭灯）”图片。

按键提示：当 Caps Lock、Num Lock、Scroll Lock 切换时，在屏幕中间短暂显示提示图片，并播放提示音，随后自动消失；

当 Shift、Ctrl、Alt、Win 单独或组合按下时，显示提示图片，同时播放提示音；按住不放，持续显示。

配置文件：没有图形设置界面，参数保存 setting.ini 文件中，文件中有注释和推荐值。*修改设置后重启程序生效。

图标菜单：任务栏图标→右键→“打开设置”、“关闭任务栏图标”、“退出”，双击图标默认打开配置文件；若图标被关闭，打开配置文件可设定恢复。

出错容错：当程序报错或显示混乱时，删除配置文件，可能恢复正常；

配置文件不存在时，会用默认参数自动重新生成；

程序发现设置参数有误（例如图片超出屏幕），会自动恢复默认参数。

如果 images、sounds 文件夹不存在、相应文件不存在或设置文件名为空，则不显示相应图片或不播放声音。

防碍事：所有指示灯和提示的图片，均鼠标穿透、不可选中、不可点击、不可移动，以免防碍用户操作其他程序。

可自定义：图片、声音、图标由用户自行设定；程序文件夹下的 images、sounds、icon 文件夹，分别存放图片、声音和任务栏图标。

程序适合希望以不碍事的方式，实时显示键盘锁定键和功能键状态的用户使用。
